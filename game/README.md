# Sky Stacker

Мобилна игра со еден допир: спушташ плочи на кулата, а секое промашување ја сече плочата.
Совршен потег дава комбо, звук што се качува по скалата и дијаманти. По 3 совршени потези
по ред плочата повторно расте.

## Што има внатре
- Изометриска графика нацртана во код (canvas): нема слики за симнување, па играта е многу лесна (~40 KB).
- 7 скинови: Dawn (бесплатен), Sunset, Ocean, Neon, Candy, Marble, Gold Rush. Ги купуваш со дијаманти.
- Дијаманти: +1 за совршен потег, +2 при комбо 5+, +5 на секои 25 ката, +20 дневен подарок.
- „Продолжи“ по пораз чини 25 дијаманти (еднаш по игра).
- Звук синтетизиран во прелистувачот, вибрации, рекорд, споделување, англиски и македонски.
- PWA: работи офлајн и се инсталира на почетниот екран (`manifest.webmanifest`, `sw.js`).

## Пробај локално
```
cd game && python3 -m http.server 8080
```
Отвори `http://<IP-на-компјутерот>:8080` на телефонот (ист Wi‑Fi).

## Како да ја продаваш (Google Play / App Store)
1. Спакувај ја со [Capacitor](https://capacitorjs.com):
   ```
   npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
   npx cap init "Sky Stacker" com.tvojafirma.skystacker --web-dir game
   npx cap add android && npx cap add ios
   npx cap open android   # Android Studio -> Build -> Generate Signed Bundle (.aab)
   ```
2. Заработка (најдобро функционира кај ваков тип игри):
   - **Rewarded реклами** (AdMob, plugin `@capacitor-community/admob`): понуди „Продолжи“ за гледање реклама
     покрај опцијата со дијаманти. Врзи го во функцијата `cont()` во `index.html`.
   - **Interstitial реклама** на секои 3–4 изгубени игри (броиш со `save.games`).
   - **Купување во апликација**: пакети дијаманти и „Без реклами“ (plugin `cordova-plugin-purchase`).
3. Сметки: Google Play Console (еднократно 25 USD), Apple Developer (99 USD годишно).
4. За продавницата: скриншотови од менито, комбо и Gold Rush скинот; кратко видео од 15 секунди
   каде кулата расте со совршени потези продава најдобро.

Пред објавување: смени го `com.tvojafirma` со вашиот домен и додај политика за приватност (задолжително кога има реклами).
